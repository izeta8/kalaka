# Kalaka — frontend

> **Outside the study scope. All the code in `frontend/` is written by AI.**
>
> Kalaka is the anchor project of a self-taught course. The backend, the
> infrastructure and the authentication are written by hand as learning work.
> The frontend is not part of that learning: it is written entirely by an AI
> agent, reviewed by the project owner as a client would. Do not read this
> folder as a sample of the owner's frontend skills.

A web client for the Kalaka API: rooms for every province and town of Euskal
Herria, with short posts and replies. Basque first, Spanish optional.

The full specification is in [SPEC.md](SPEC.md).

## Run it

The frontend and the API live on **different origins** on purpose, in
development as in production. The browser calls the API directly (no dev proxy),
so the API must allow this origin with CORS.

```bash
cp .env.example .env   # VITE_API_URL=http://localhost:3000
npm install
npm run dev            # http://localhost:5173
```

With `VITE_API_MOCK=false` in `.env`, the API must be running (see `../backend`)
with `http://localhost:5173` in its allowed origins.

### Mock mode (no backend)

```bash
npm run dev:mock       # vite --mode mock, reads .env.mock
```

MSW answers every API call in the browser with the handlers in `src/mocks/`
(the same ones the tests use): the real provinces and some real towns from the
seed, fake users and posts. Posts and replies you publish stay in memory until
you reload. `VITE_API_MOCK=true` in `.env` does the same with `npm run dev`.
The service worker (`public/mockServiceWorker.js`) is generated by
`npx msw init public` and only runs in mock mode.

## Scripts

| Script | What it does |
|---|---|
| `npm run dev` / `dev:mock` | Dev server, against the API or the mocks |
| `npm run build` | Type-check and build to `dist/` |
| `npm run lint` | oxlint |
| `npm test` / `test:watch` | Vitest + Testing Library + MSW |
| `npm run format` / `format:check` | Prettier |
| `npm run maps:download` | Download the map sources (IGN/CNIG for Hegoalde, IGN France/Etalab for Iparralde) into `scripts/sources/` |
| `npm run maps:build` | Build `src/data/maps/*.topo.json` and `src/data/town-municipalities.json` (see SPEC.md, "Maps") |
